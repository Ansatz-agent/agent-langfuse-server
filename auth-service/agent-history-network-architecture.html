Agent History Portal：网络与数据架构

当前生产拓扑（实线）与未来重制推荐方向（虚线）。门户当前通过 c2sml.cn/agent/ 挂载；长期应迁移至独立 agent.c2sml.cn origin。

关键请求流

  • 浏览器以 HTTPS 进入反代。
  • NPM 仅为 `/agent/` 剥离前缀并转发可信头。
  • 应用只在私网 `agent-history-web:8000` 服务。
  • Owner scope 在应用数据访问层而非模板层执行。

关键数据流

  • 可信本机 JSON/JSONL → 校验 → 二次脱敏 → 原子导入。
  • Session 与 Message 保留 raw metadata 和 typed usage。
  • Export 以 root JSONL 行输出，合法 threads 嵌套。
  • Context allocation 是派生估算，精确 tokens 是 session 累计。

重制硬约束

  • 应用端口、数据库端口、健康细节不得公网暴露。
  • 跨 Owner child 不得参与任何聚合或页面。
  • 备份必须一致性校验并实际恢复演练。
  • 迁移子域和替换数据库时不得破坏主站既有路由。
